🌸 FocusFlow – AI-Based Productivity Tracker
🧠 Overview

FocusFlow is an AI-powered productivity tracker that helps users monitor, analyze, and enhance daily performance.
It uses AI insights, smart scheduling, and emotional feedback to encourage better focus, goal completion, and balance.
Built using Flutter, FocusFlow combines AI intelligence with aesthetic calmness, designed in Rani Pink (#e11584) with pastel peach, mint, and cream tones.

✨ Key Features

🌸 Personalized Dashboard – Focus score, streaks, and AI insights.

🧠 MindSync AI Assistant – Predicts productivity trends and provides focus suggestions.

✅ Task Integration Placeholders – ClickUp, Trello, Asana, Notion, Wrike, Monday, and Clockwise.

⏱️ Pomodoro Timer – Circular, animated timer for focus sessions.

🗓️ Smart Calendar – Minimal beige calendar to plan tasks and goals.

💬 Notes + AI Summary – Quick reflection area with “✨ Ask AI to Summarize.”

🌿 Analytics & Insights – View progress, focus patterns, and completion score.

🎨 Aesthetic Theme – Rani Pink as the core color, with pastel gradients and rounded designs.

⚙️ Installation & Setup

1️⃣ Prerequisites

Install Flutter SDK

Run flutter doctor to verify setup

Use VS Code or Android Studio

2️⃣ Clone Repository

git clone https://github.com/yourusername/focusflow.git
cd focusflow


3️⃣ Install Dependencies

flutter pub get


4️⃣ Run Application

flutter run
